# Исходная версия проекта

Проверена чистая ветка `main` на коммите `f78760d`. Тег `baseline-v1` указывает на тот же коммит. У репозитория отсутствуют настроенные удалённые адреса. Исходные файлы данных и команды оценки остались доступны в v2.

| Часть | Состояние на момент аудита |
| --- | --- |
| Задача | Помощник первой линии поддержки онлайн-школы с четырьмя очередями и ручным разбором |
| API и браузер | Локальный HTTP-сервер и `POST /api/predict`, ручной ввод и примеры, оценки очередей |
| Решения | Выбор оставался надписью в браузере. Базы и истории событий не было |
| Данные | 120 синтетических строк для обучения и 120 для теста, без validation и challenge |
| ML | Символьный TF-IDF, логистическая регрессия, некалиброванная оценка, фиксированный порог 0,60 |
| Экономика | CLI и расчёт одного внедрения, условные времена и объём, монетизация всех сэкономленных часов |
| Защита | Сценарий и ответы в Markdown. В проверенной истории файла презентации нет |
| Воспроизводимость | Закреплённые зависимости и README, без автоматизированных тестов |
